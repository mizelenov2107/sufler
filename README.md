# Суфлёр

Нативное приложение для macOS: панель с текстом занятия поверх презентации. Слушает речь
через микрофон, ведёт строку вслед за ней, показывает, когда переключать слайд,
и в демонстрацию экрана не попадает.

**Стек:** Swift, AppKit + SwiftUI, Speech (распознавание на устройстве), AVFoundation,
Carbon (глобальные клавиши), ScreenCaptureKit. Сборка одним вызовом `swiftc`, без Xcode-проекта.

## Сборка и запуск

```bash
./sborka.sh                       # собирает build/Суфлёр.app
open build/Суфлёр.app             # открывает список уроков
open build/Суфлёр.app --args "путь/к/Суфлёр — тема.md"   # мимо списка, сразу в ведение
```

При запуске суфлёр показывает список уроков и кнопку «Вставить текст…»: он сам обходит папку заметок Obsidian
и собирает все заметки, чьё имя начинается со слова «Суфлёр». В строке стоят тема, папка занятия, число разделов,
хронометраж и дата правки, сверху есть поиск. Клик по строке начинает ведение,
и время занятия идёт с нуля. Кнопка «Другой файл…» открывает заметку,
которая лежит вне этой папки. Вернуться к списку можно по `⌥O`.

Когда готовой заметки нет, речь вставляется прямо в приложение: кнопка
«Вставить текст…» или `⌥V` открывает поле, куда текст кладётся как есть.
Разметка там не нужна, суфлёр читает его по простым правилам:

| В тексте | На панели |
|---|---|
| пустая строка | конец абзаца |
| строка с решёткой | заголовок раздела |
| строка с отступом в четыре пробела | выкладка |
| `*(строка в звёздочках)*` | ремарка, вслух не читается |

Внизу окна видно, сколько там слов и на сколько минут речи это тянет.
Кнопка «Вести» (или `⌘↵`) начинает занятие, а сам текст остаётся в файле
`~/Library/Application Support/Суфлёр/Вставка.md`, так что после перезапуска
он никуда не денется и правится по `⌥R`.

Первый запуск спрашивает микрофон и распознавание речи. Распознавание идёт
на устройстве; если русской модели нет, суфлёр сам уходит на серверное и пишет
об этом в шапке.

## Клавиши

Работают из любой программы, фокус у презентации не отбирают.

| Клавиши | Что делает |
|---|---|
| `⌥ Пробел` | пауза и продолжение, микрофон выключается |
| `⌥ →` `⌥ ←` | шаг через предложение |
| `⌥ ⇧ →` `⌥ ⇧ ←` | шаг через абзац |
| `⌥ ↑` `⌥ ↓` | кегль |
| `⌥ B` | плотность фона, четыре ступени |
| `⌥ C` | клики проходят сквозь панель |
| `⌥ H` | спрятать и вернуть панель |
| `⌥ R` | перечитать файл после правки |
| `⌥ O` | вернуться к списку уроков |
| `⌥ V` | вставить текст занятия |
| `⌥ T` | время занятия с нуля |
| `⌥ Q` | закрыть суфлёр |

Мышью: клик по слову ставит суфлёр на это слово, клик по абзацу или по делению
рейки внизу переносит на его начало. Панель таскается за любое место фона.
В правом верхнем углу панели две кнопки, спрятать и закрыть.

Иконки в доке у суфлёра нет, зато в строке меню стоит значок с теми же командами,
включая выход. Он же говорит, что приложение ещё работает.

## Как читается файл

Разбирается разметка заметки суфлёра (Markdown, например из Obsidian):

| В файле | На панели |
|---|---|
| `## 04 · Что делают k и b · 3 шага · 3 мин` | заголовок слайда, минуты идут в хронометраж |
| обычный абзац | речь, по ней ведётся строка |
| `**Клик 1** — появляется прямая` | розовая плашка, подсвечивается в свой момент |
| `**Пробел.**` | синяя плашка перехода на следующий слайд |
| `*(ждём ответ, нужно 6)*` | ремарка, вслух не читается |
| строка с отступом в четыре пробела | выкладка |

Всё до первого `## NN · ` и после конца слайдов не показывается, так что шапка
заметки и таблица сокращений панели не мешают.

## Пропуск слов

Матчер ищет услышанное слово в ближайших 34 словах текста, поэтому пропущенные
слова и целые обороты проглатываются сами. Если речь ушла далеко, то место
восстанавливается по двум подряд услышанным словам в пределах 700 слов вокруг
курсора или по одному длинному слову, которое в этом куске встречается один раз.
Совпадение считается по первым пяти буквам, так что падеж и число роли не играют.

Строка внизу панели показывает, что именно услышал распознаватель. Если она
пустая, то дело в микрофоне, а не в суфлёре.

## Устройство

| Файл | Что внутри |
|---|---|
| `Sources/Skript.swift` | разбор заметки на блоки и слова |
| `Sources/Sovpadenie.swift` | матчер речи и текста, ручные шаги |
| `Sources/Sluh.swift` | микрофон и распознавание, перезапуск задачи раз в минуту |
| `Sources/Okno.swift` | панель поверх всего и её вид |
| `Sources/main.swift` | сборка целого, глобальные клавиши |

Переменная `SUFLER_VIDIM=1` включает панель в захват экрана: нужна, только чтобы
снять с суфлёра скриншот.

## Где лежат заметки

Список уроков собирается из ваулта Obsidian. По умолчанию суфлёр смотрит
в `~/Documents/Obsidian Vault`, а другой путь задаётся переменной окружения:

```bash
SUFLER_VAULT="~/Заметки" open build/Суфлёр.app

# на большой базе заметок поиск сужается до одной папки
SUFLER_PAPKA="Занятия" open build/Суфлёр.app
```

Внутри папки берутся все файлы `.md`, чьё имя начинается со слова «Суфлёр»
и внутри которых есть хотя бы один заголовок вида `## 03 · Тема · 2 мин`.

## «Суфлёр · вопросы»

Второе приложение из того же репозитория (`Voprosy/main.swift`, сборка `./sborka-voprosy.sh`)
помогает с ответами на вопросы по материалам своего доклада на созвоне. Оно слушает звук
созвона через ScreenCaptureKit (или микрофон), распознаёт вопрос и отправляет его в постоянно запущенный процесс
Claude Code (`claude -p` в режиме stream-json), у которого в системном промпте лежат материалы
доклада. Ответ стримится в панель поверх окна. Файл материалов задаётся первым аргументом или
переменной `SUFLER_MATERIALY` и в репозиторий не входит.

`proba/main.swift` — консольная проверка матчера на тексте заметки.
